# 惜住 7.30｜山林守護挑戰

給直式 LG 閨密機／活動觸控螢幕使用的計時遊戲。`7.30` 代表「惜山林」；玩家按住畫面下方的森林種子開始計時，在 **7.30 秒**放開即成為山林守護者並獲得大獎。每位玩家共有三次機會。

## 開啟方式

在本資料夾執行：

```bash
npm start
```

同一台裝置開啟 `http://localhost:8888`。若要讓 LG 閨密機直接連線，請讓電腦與閨密機連上同一個 Wi-Fi，然後在閨密機瀏覽器輸入電腦的區域網路網址，例如 `http://192.168.1.20:8888`。

LG webOS／低效能觸控裝置會自動使用流暢特效模式。若裝置沒有被自動辨識，可在網址後加上 `?effects=lite`，例如 `http://192.168.1.20:8888/?effects=lite`；需要強制顯示完整粒子效果時則使用 `?effects=full`。

主版型以直式 `1080 × 1920` 設計。水彩森林背景全程常駐；森林種子包含待機、蓄能、自然張開與嫩芽成樹四個狀態，MORI 松鼠包含躲藏、鼓勵與歡呼狀態。網頁載入壓縮後的 WebP，PNG 與完整狀態圖保留作為高品質原始素材。

## 現場操作

- 按住森林種子：立即開始計時，種子會隨時間逐漸發亮。
- 在 `7.30` 秒放開：直接鎖定放手當下螢幕已顯示的數字，放手後不再重新計算或改寫成績。
- 倒數數字會同步發光，數字後方的水彩生命樹會隨時間長大、變亮。
- 互動音效包含開始注入、蓄能漸強、接近 7.30 提示、放手釋放、失敗鼓勵、中獎成長與 MORI 歡呼；右上角可隨時開關音效。
- 未中獎後直接再次按住種子即可挑戰；三次結束後點「下一位玩家」會重新開始。
- 每次未命中的生命能量仍會累積，讓森林逐次增加嫩芽、花朵與光點。
- 工作人員按 `R`：隨時重置本局。
- 右上角「全螢幕」：進入／離開全螢幕。
- 右上角「預覽」：不用等待 7.30 秒，直接查看種子長成小樹與 MORI 歡呼的成功畫面。

## 判定方式

遊戲採嚴格模式並以百分之一秒顯示，放開時畫面顯示 `7.30` 才算中獎，對應約 10 毫秒的命中區間。
